# Tip Calculator

Split a tip fairly. Enter the bill amount, pick the service quality, and the number of people — it shows the tip amount per person.


## Features

- Bill amount input
- Service quality levels: **Excellent** (25%), **Good** (20%), **Average** (15%), **Below Average** (10%), **Poor** (5%)
- Split across any number of people (the "each" label hides for a single person)
- Tip shown in ₹, rounded to 2 decimals

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

Just open `index.html` in any browser. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000
```

## Example

A ₹1000 bill, Good service (20%), split across 4 people gives a tip of **₹50 each**.
